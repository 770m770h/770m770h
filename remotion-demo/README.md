# "אנשים" — סרט פרסומת שנכתב כקוד

פרסומת למותג בתחום **יחסי אנוש**, שנבנתה כולה כ‑React עם
[Remotion](https://www.remotion.dev/) — חמש סצנות, דמויות מונפשות, תנועת מצלמה
ומעברים. בלי טיימליין, בלי צוות וידאו.

1920×1080 · 528 פריימים @ 30fps (17.6 שניות)

![poster](out/poster.png)

## התסריט

| # | סצנה | קומפוזיציה |
|---|------|-----------|
| 1 | **הבוקר** | שוט רחב מבסס — עיר עם שחר, דמות בהליכה, מצלמה נכנסת פנימה בהאטה |
| 2 | **העומס** | פנים, מדיום/קלוז' — סופת ניירת, מצלמת יד רועדת, קצב מהיר |
| 3 | **הפלטפורמה** | שדה גרפי איזומטרי — הכאוס מתארגן לכרטיסים מחוברים |
| 4 | **אנשים** | קלוז' חם של לחיצת יד שנפתח ברצף אחד לצוות שלם |
| 5 | **נעילת מותג** | לוגו מתכנס, דמויות ממשיכות ללכת ברקע |

המעברים משתנים לפי המשמעות: דיזולב בין הבוקר לעומס, **ניגוב** בנקודת המפנה אל
הפלטפורמה, **הסטה** מהמערכת אל בני האדם, ודיזולב שקט אל הנעילה.

## ריג הדמויות

`src/rig.tsx` הוא שלד עם מפרקים (ירך, ברך, כתף, מרפק) שמחשב זוויות **לפי הפריים** —
לא תמונות מוכנות. שמונה תנוחות: `walk`, `idle`, `sit`, `type`, `handshake`, `wave`,
`cheer`, `think`. איברים רחוקים מצוירים כהים יותר ומאחורי הגוף, קרובים מלפנים — כך
מתקבל עומק והצעד נקרא.

`src/probe/rigsheet.tsx` הוא גיליון בדיקה שמרנדר את כל התנוחות; הוא זה שחשף שני באגים
אמיתיים: דמויות בישיבה ריחפו באוויר, ומחזור ההליכה לא נקרא כי הרגליים התמזגו לגוש
והזרועות נעלמו על רקע גוף באותו צבע.

## שפת עיצוב

- **עברית מלאה, RTL.** בלי סגול, בלי ניאון, בלי זוהר, בלי אמוג'י.
- פלטה חמה: נייר `#ECE4D3`, דיו `#211B13`, ירוק‑אורן `#1E5A44`, טרקוטה `#B9552F`.
- טיפוגרפיה עברית: **Frank Ruhl Libre** (סריף תצוגה) + **Assistant** (סן‑סריף).
- הגופנים **מוטמעים מקומית** (`public/fonts/*.woff2`) ונטענים דרך `@font-face` +
  `delayRender` — לדפדפן ה‑headless אין גופן עברי, לכן זה חיוני.

## רינדור

Remotion מרנדר עם Chrome headless. בסביבה הזו קיים `chrome-headless-shell` מותקן
מראש, לכן מעבירים אותו במפורש:

```bash
HS=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell

npm run render -- --browser-executable="$HS"   # → out/anashim-film.mp4
npm run still  -- --browser-executable="$HS"   # → out/poster.png
```

לבדיקת סצנה בודדת:

```bash
npx remotion still src/probe/arrival.tsx Probe out/x.png --frame=70 --browser-executable="$HS"
```

במחשב רגיל משמיטים את `--browser-executable` ו‑Remotion מוריד Chrome בעצמו.
